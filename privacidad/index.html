Con quién se comparten

Con los servicios que usamos para funcionar: MailerLite (emails), Gumroad (pagos) y, si se usa, Zapier (conexión entre ambos). Esta web está alojada en GitHub Pages. Algunos pueden tratar datos fuera del Espacio Económico Europeo con las garantías que exige el RGPD. Cuando ocurre, se apoya en los mecanismos que reconoce el RGPD, como las cláusulas contractuales tipo o el Marco de Privacidad de Datos UE-EE. UU.

Cuánto tiempo

Newsletter: mientras sigas suscrito. Compras: el plazo que exija la normativa fiscal.

Tus derechos

Puedes pedir acceso, rectificación, supresión, oposición, limitación y portabilidad escribiendo a hola@finalmente.money. Darte de baja de la newsletter es un clic desde cualquier email. Si crees que no se respetan tus derechos, puedes reclamar ante la Agencia Española de Protección de Datos (aepd.es).
